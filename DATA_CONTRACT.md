# Data Contract

This document defines the strict boundary between the **System layer** (the core engine, CLI, and test suite) and the **User layer** (personal session configs, target lists, campaigns, and outputs).

---

## 1. Principles

1. **Local-First & Zero Cloud**: Your session cookies, Chrome user profile, and outreach history never leave your local machine. No external telemetry or cloud servers.
2. **Strict Isolation**: User target lists, harvested profiles, personalized notes, and local mutex locks are gitignored and excluded from version control.
3. **Turnkey Clone-and-Run**: Anyone cloning this repository gets a clean workspace with all necessary directories scaffolded (`data/`, `campaigns/`, `scratch/`).
4. **Safe Upstream Updates**: Running `git pull` updates the system engine without overwriting your local configuration (`.linkedin-opsrc`), campaigns, or harvested data.

---

## 2. The Two Layers

### User Layer (NEVER committed to git / NEVER overwritten by updates)

These files contain your personal credentials, Chrome configurations, outreach targets, and campaign outputs. They are protected by `.gitignore`.

| Path | Purpose |
|------|---------|
| `.linkedin-opsrc` | Local machine configuration (Chrome executable path, user data directory, selected profile) generated by `node index.mjs setup`. |
| `start-chrome.command` / `start-chrome.bat` | One-click desktop launcher scripts generated by setup for port 9222. |
| `data/*` | Harvested profile JSONs, search exports, and candidate lists (except `data/.gitkeep`). |
| `campaigns/*.mjs` | Custom user-written batch outreach or search scripts (except `campaigns/*.example.mjs`). |
| `scratch/*` | Ad-hoc inspection and debugging scripts (except `scratch/.gitkeep`). |
| `*.log` | Runtime execution and error logs. |

### System Layer (Safe to update via git pull)

These files constitute the open-source platform. They are tracked in git and maintained upstream.

| Path | Purpose |
|------|---------|
| `index.mjs` | Unified CLI entry point (`connect`, `dm`, `comment`, `search`, `doctor`, `setup`, `lock`). |
| `src/actions/` | LinkedIn DOM interaction modules (`connect.mjs`, `dm.mjs`, `engage.mjs`, `search.mjs`). |
| `src/browser-manager.mjs` | Cross-platform Chrome binary detection, profile discovery, and SingletonLock handling. |
| `src/tab-manager.mjs` | Isolated ephemeral tab lifecycle management (`PUT /json/new` and cleanup). |
| `src/lock.mjs` | Cross-process mutex locking (`withLock`) and local config loader. |
| `src/cdp.mjs` | Low-level Chrome DevTools Protocol WebSocket client and evaluators. |
| `src/doctor.mjs` | Pre-flight diagnostics and OS-specific remedy generator. |
| `src/setup.mjs` | Interactive terminal setup wizard. |
| `test/` | Automated unit test suite executed via `npm test`. |
| `docs/` | Architecture specs, engineering plans, and technical documentation. |
| `campaigns/batch-connect.example.mjs` | Reference template for user batch campaigns. |
| `package.json` | Package manifest, scripts, and runtime engine constraints. |
| `LICENSE` | MIT License terms. |
| `README.md` | Quickstart guide, architecture guarantees, and CLI reference. |
| `DATA_CONTRACT.md` | Canonical definition of the system/user file contract. |
